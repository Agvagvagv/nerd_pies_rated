# Душные пирожки

Текстовый архив авторского Telegram-канала [«Душные пирожки» (@nerd_pies)](https://t.me/nerd_pies): пирожки, порошки, депрессняшки, двустишия и диптихи, то есть сетевая микропоэзия с уклоном в науку, литературу, историю и прочее занудство.

В канале каждый текст выходит картинкой, поэтому здесь собраны их текстовые версии, чтобы их можно было найти поиском и прочитать без Telegram.

**[Все опубликованные тексты → pies.md](pies.md)**

Список обновляется автоматически раз в сутки (в 00:00 UTC) и отсортирован по числу реакций в канале: сначала самые популярные. У каждого текста есть ссылка на пост, где под спойлером часто прячется комментарий «пояснительной бригады» с разбором отсылок и аллюзий.

## Что такое пирожок

Пирожок — короткое стихотворение из четырёх строк, написанное четырёхстопным ямбом (9-8-9-8 слогов), без рифмы в первой и третьей строках, со строчными буквами и без знаков препинания. Порошок устроен так же, но последняя строка у него укорочена до двух слогов.
